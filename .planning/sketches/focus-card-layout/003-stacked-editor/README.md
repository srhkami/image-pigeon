## Variant: 003-stacked-editor

### Design stance
003-stacked-editor explores a distinct focus-card interaction for the left editing area while keeping the right Word preview synced to the focused image.

### Key choices
- Single-file HTML/CSS/JS mockup.
- Uses realistic image order and auto-layout examples.
- Click cards/rows or navigation buttons to change focus.

### Trade-offs
- This is a disposable visual sketch, not production React code.
