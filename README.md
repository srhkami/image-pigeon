# 貼圖小鴿手

`Version` **2.0.0**

`What's New`
- 新增自動拼貼排版預覽，會依圖片方向自動組成橫圖、直向大圖、直向小圖與混合頁面
- 新增焦點式圖片編輯介面，可用滑鼠滾輪或方向鍵切換目前圖片，並支援直向圖片大小切換
- Word 輸出改用自動拼貼版型，支援混合橫向圖片與直向小圖排版
- 操作按鈕整合到左側側邊欄，與編輯區、預覽區維持同層級，不再遮住圖片內容
- 右側頁面縮圖預覽縮小，樣式更接近 A4 影印結果
- 排序模式改為獨立清單並改善拖曳流暢度，降低抖動與卡頓
- 修復新版提示視窗重複彈出、頁面高度被撐開與焦點圖片無法置中的問題
- 修正旋轉圖片後仍以原方向判斷排版的問題
- 修正 Word 橫向圖片編號欄過寬、直向小圖高度與混合版型跑版問題

### ⭐ 特色功能
- 自動帶入備註
- 自動壓縮圖片
- 自動分割長截圖
- 焦點式圖片編輯、旋轉、備註與直向大小切換
- 排序模式快速拖曳排序
- 自動拼貼頁面預覽，接近最終 Word / 影印結果
- 儲存新版專案、開啟專案
- 輸出 Word、壓縮過的圖片
- 匯入舊版 JSON 專用檔案

### 📢 推薦技巧
#### ✅我想快速製作黏貼表
1. 點選左側「導入圖片」，設定預設備註並匯入圖片
2. 在焦點式編輯區修改個別備註、旋轉圖片、調整直向圖片大小
3. 參考右側頁面縮圖預覽確認自動拼貼版型
4. 點選左側「輸出檔案」輸出 Word，完成！

#### ✅我想整理照片
1. 匯入所有圖片
2. 開啟左側「排序模式」快速拖曳排序圖片
3. 關閉排序模式後可繼續編輯備註與旋轉
4. 輸出圖片，就能得到壓縮且有序的圖片！

#### ✅我想保留編輯紀錄
1. 匯入圖片，編輯及排序
2. 在「輸出檔案」中選擇「儲存專案」，輸入專案名稱並儲存成 `.ipigeon` 專案資料夾
3. 下次即可用「開啟專案」繼續編輯！

#### ✅我有舊版 JSON 專用檔案
1. 點選「導入圖片」
2. 選擇「讀取舊檔」
3. 選取 `.json` 檔案匯入，匯入後可再儲存為新版專案
