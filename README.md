# 貼圖小鴿手

`Version` **3.0.0**

`What's New`
- 全面改為純前端處理，圖片匯入、壓縮、長截圖切割、專案管理與輸出皆在本機瀏覽器完成。
- 專案統一儲存為單一 `.ipigeon` 檔案，不再支援舊版 JSON 或 `.ipigeon/` 專案資料夾。

---

### 📌 這是什麼

現場照片、對話截圖、轉帳明細、監視器畫面......

你是否因為如何整理這些圖片而感到苦惱呢？

放心！這個小工具就是來解決你的困擾的！

### ⭐ 特色功能
- 自動帶入備註
- 自動壓縮圖片
- 自動分割長截圖
- 圖片編輯、旋轉與大小切換
- 快速拖曳排序
- 自動拼貼頁面預覽
- 儲存專案，保留編輯進度
- 輸出 Word、壓縮過的圖片

### 📢 推薦技巧
#### ✅我想快速製作黏貼表
1. 點選「導入圖片」按鈕，設定預設備註
2. 在焦點式編輯區修改個別備註、旋轉圖片、調整直向圖片大小
3. 參考右側頁面縮圖預覽確認自動拼貼版型
4. 點選「輸出檔案」按鈕，即可列印或輸出 Word！

#### ✅我想整理照片/保留編輯記錄
1. 開啟「排序模式」快速拖曳排序圖片
2. 在「輸出檔案」中選擇「儲存專案」，會下載單一 `.ipigeon` 專案檔
3. 下次即可用「開啟專案」繼續編輯！圖片順序、排版依舊不變！
