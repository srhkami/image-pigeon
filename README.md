# 貼圖小鴿手

`Version` **1.7.0**

`What's New` 
- 新版專案格式改為 `.ipigeon` 資料夾，保存 `project.json` 與圖片檔案
- 新增「儲存專案」與「開啟專案」，可保留圖片排序、備註與旋轉狀態
- 「輸出檔案」新增「儲存專案」分頁，可自訂專案名稱
- 圖片匯入改用本機 FastAPI session 暫存，降低大量圖片處理負擔
- 匯入圖片與讀取舊檔現在會限制可選副檔名
- 開啟專案前會提示將清除目前預覽圖片，避免誤覆蓋目前工作

### 📌 這是什麼

現場照片、對話截圖、轉帳明細、監視器畫面......

你是否因為如何整理這些圖片而感到苦惱呢？

放心！這個小工具就是 來解決你的困擾的！


### ⭐ 特色功能
- 自動帶入備註
- 自動壓縮圖片
- 自動分割長截圖
- 排序、旋轉、合併圖片
- 儲存新版專案、開啟專案
- 輸出 Word、壓縮過的圖片
- 匯入舊版 JSON 專用檔案

### 📢 推薦技巧
#### ✅我想快速製作黏貼表
1. 編輯預設備註，匯入圖片
2. 修改個別備註、排序照片
3. 輸出成Word檔，完成！

#### ✅我想整理照片
1. 匯入所有圖片
2. 使用「排序模式」快速排序圖片
3. 輸出圖片，就能得到壓縮且有序的圖片！

#### ✅我想保留編輯紀錄
1. 匯入圖片，編輯及排序
2. 在「輸出檔案」中選擇「儲存專案」，輸入專案名稱並儲存成 `.ipigeon` 專案資料夾
3. 下次即可用「開啟專案」繼續編輯！

#### ✅我有舊版 JSON 專用檔案
1. 點選「導入圖片」
2. 選擇「讀取舊檔」
3. 選取 `.json` 檔案匯入，匯入後可再儲存為新版專案
