### 📌 這是什麼

現場照片、對話截圖、轉帳明細、監視器畫面......

你是否因為如何整理這些圖片而感到苦惱呢？

放心！這個小工具就是來解決你的困擾的！

### ⭐ 特色功能
- 自動帶入備註
- 自動壓縮圖片
- 自動分割長截圖
- 焦點式圖片編輯、旋轉、備註與直向大小切換
- 排序模式快速拖曳排序
- 自動拼貼頁面預覽，接近最終 Word / 影印結果
- 輸出流程加上「預覽列印」入口，可先確認 A4 分頁、標題、頁碼與備註欄再列印
- 儲存新版專案、開啟專案
- 輸出 Word、壓縮過的圖片
- 匯入舊版 JSON 專用檔案

### 📢 推薦技巧
#### ✅我想快速製作黏貼表
1. 點選左側「導入圖片」，設定預設備註並匯入圖片
2. 在焦點式編輯區修改個別備註、旋轉圖片、調整直向圖片大小
3. 參考右側頁面縮圖預覽確認自動拼貼版型
4. 點選左側「輸出檔案」輸出 Word，完成！

#### ✅我想整理照片
1. 匯入所有圖片
2. 開啟左側「排序模式」快速拖曳排序圖片
3. 關閉排序模式後可繼續編輯備註與旋轉
4. 輸出圖片，就能得到壓縮且有序的圖片！

#### ✅我想保留編輯紀錄
1. 匯入圖片，編輯及排序
2. 在「輸出檔案」中選擇「儲存專案」，輸入專案名稱並儲存成 `.ipigeon` 專案資料夾
3. 下次即可用「開啟專案」繼續編輯！

#### ✅我有舊版 JSON 專用檔案
1. 點選「導入圖片」
2. 選擇「讀取舊檔」
3. 選取 `.json` 檔案匯入，匯入後可再儲存為新版專案
